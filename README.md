# 🐆 Jaguar Game Engine - Resources & Editor Assets (مستودع موارد محرك جيكوار)

مستودع الموارد الرسمي لـ **محرك الألعاب جيكوار (Jaguar Game Engine)**. يحتوي هذا المستودع على جميع الموارد، التخفيات البصرية، واجهات المستخدم، ومواصفات لغة البرمجة الخاصة بالمحرك **TRQ (تركيو)**.

---

## 📁 هيكلية المستودع (Repository Architecture)

- **`editor/`**: المجلد الرئيسي لكافة موارد المحرر.
  - **`lang/`**: مواصفات لغة **TRQ (تركيو)**، القواعد البرمجية، والمستندات والأمثلة.
    - `spec/trq_spec.json`: المفسر المصدري لقواعد ومفردات لغة TRQ.
    - `samples/cube_hover_animation.trq`: مثال كامل لتحريك مكعب عند مرور الماوس عليه بلغة TRQ.
    - `templates/`: قوالب السكريبت الجاهزة للاستخدام.
  - **`ui/`**: ثيمات المحرر، الألوان، الخطوط والتصاميم البصرية.
  - **`icons/`**: أيقونات الأدوات، شريط المهام، وأزرار التحكم.
  - **`widgets/`**: إعدادات محرر الكود والإكمال التلقائي للتأثيرات والأزرار.
  - **`layouts/`**: تخطيطات الواجهة الافتراضية للمحرر.
  - **`presets/`**: الأشكال والخصائص ثلاثية الأبعاد الافتراضية (Cube, Sphere, Light, Materials).
- **`manifest.json`**: الدليل الرئيسي الذي يقرأه تطبيق المحرك لمعرفة إصدار الموارد وبصمة SHA-256 للملف المضغوط.
- **`build_resources.py`**: سكريبت Python أوتوماتيكي لضغط الموارد وحساب البصمة وتحديث الدليل.
- **`editor-resources.zip`**: الملف المضغوط النهائي الذي يقدمه المستودع لتطبيق المحرك.

---

## 📜 لغة البرمجة TRQ (Turqia Scripting Language)

لغة **TRQ** هي لغة برمجة نصية مخصصة ومبسطة صُممت خصيصًا لمحرك جيكوار لتسمح للمستخدم بإنشاء تفاعلات وسلوكيات الألعاب بسهولة.

### 💡 مثال (Example): تحريك مكعب عند لمس الماوس
```trq
Code TRQ 
Code cube
Cube.find
Cube name(red cube)

Event
Find tosh
Mouse.point to cube

Effiect service
Move down
Move up 
End

End   end
```

## 🔄 كيفية تحديث الموارد والتأكد من جاهزيتها للمحرك

عند إضافة أو تعديل أي موارد في مجلد `editor/`، قم بتشغيل سكريبت التجميع الأوتوماتيكي:

```bash
python3 build_resources.py
```

يقوم السكريبت تلقائيًا بـ:
1. ضغط مجلد `editor/` إلى `editor-resources.zip`.
2. حساب بصمة التشفر **SHA-256** وحجم الملف.
3. تحديث ملف `manifest.json` تلقائيًا.

ثم قم برفع التعديلات إلى GitHub:
```bash
git add .
git commit -m "Update Jaguar Editor resources & TRQ language"
git push origin main
```
